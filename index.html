Sobre o projeto

Este projeto utiliza algoritmos de aleatoriedade para gerar missões diferentes a cada tentativa. O sistema utiliza JavaScript, condicionais, repetição e manipulação de textos.

💻 Tecnologias utilizadas

  • HTML: estrutura da página.
  • CSS: aparência e organização visual.
  • JavaScript: funcionamento do programa.
  • Math.random(): geração de números aleatórios.
  • if e else: criação de condições.
  • for...of: repetição e verificação dos dados.
  • replace(): substituição de palavras.
  • export e import: organização do código em módulos.
